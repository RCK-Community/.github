# RCK Community

### Building better RPG tools, together.

We maintain **RPG Creation Kit — Community Edition**, a community fork of Silvematt's RPG Creation Kit for Unity. Our focus is practical: current Unity support, URP rendering, focused bug fixes, and better editor tools for people starting their next RPG.

| Our focus | What it means |
| --- | --- |
| **Modern Unity** | Unity 6, the Input System, and URP |
| **Useful improvements** | Fixes and editor workflows shaped by real projects |
| **Compatibility** | Respect for existing content, identifiers, and official releases |
| **Collaboration** | Focused changes the original author can adopt individually |

## For verified kit owners

The Community Edition repository is **private** and available only to verified owners of RPG Creation Kit. It contains paid kit content; it is not an open-source distribution or a substitute for purchasing the original kit.

If you already have access, start with the [project README](https://github.com/RCK-Community/rpg-creation-kit-ce#readme), explore the [roadmap](https://github.com/RCK-Community/rpg-creation-kit-ce/blob/main/Docs/Architecture/ROADMAP.md), or report an edition-specific problem in [Issues](https://github.com/RCK-Community/rpg-creation-kit-ce/issues). These links require repository access.

For access, contact a community organization maintainer through your existing RCK community channel. Ownership verification is handled privately; please do not post purchase receipts or personal information in public issues.

## Built on RPG Creation Kit

RPG Creation Kit is created by **Silvematt**. The Community Edition is a community effort, not an official release. We keep changes focused and preserve official imports so improvements can flow back to the original kit.

**[Read the official RCK documentation →](https://silvematt.com/URPGCreationKitDocumentation/index.php/Special:AllPages)**

Original kit content and bundled third-party assets remain subject to their respective licenses and purchase terms. This public profile contains no kit source or assets.
